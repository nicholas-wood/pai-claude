Evaluating probabilistic components in a Retrieval-Augmented Generation (RAG) pipeline requires tracking uncertainty and accuracy at every step. You can measure pipeline quality in Melbourne by breaking it into distinct steps. Here is how to score each probabilistic part.1. Retriever EvaluationThe retriever fetches relevant documents from your database using math and probability. It calculates how close a question is to a document.Cosine Similarity: This measures the angle between vectors. Vectors are lists of numbers that represent text meaning. A score close to 1 means the text is a perfect match. A score near 0 means no match.Mean Reciprocal Rank (MRR): This checks where the right document appears in the list. The formula is \(\frac{1}{\vert{}Q\vert{}} \sum_{i=1}^{\vert{}Q\vert{}} \frac{1}{rank_i}\). If the best document is first, the score is 1. If it is second, the score is 0.5.Normalized Discounted Cumulative Gain (NDCG): This checks if the most important documents are at the top of the list.Track these scores using tools like [Ragas][1] or [TruLens][2].2. Generator EvaluationThe generator creates the final answer. Large language models (LLMs) output probabilities for every word they write.Faithfulness: This checks if the answer uses only the retrieved documents. It measures if the LLM made up false information. You can use frameworks like [DeepEval][3] to measure this as a percentage.Answer Relevance: This checks if the generated answer directly addresses the user's question.Perplexity: This measures how surprised the model is by the text it reads or writes. A low perplexity means the model is very sure of its answers.3. End-to-End EvaluationYou also need to test the whole pipeline together.Ground Truth Comparison: Ask human experts to create a set of perfect answers for a list of questions. Compare your pipeline's answers to the perfect answers.LLM-as-a-Judge: Use a powerful model like GPT-4 to grade your RAG pipeline's outputs on a scale from 1 to 5.
